    Theory sheet

    Equations that anchor design decisions

    Use them for first-order estimates, then measure the actual engine and hardware.

    KV cache capacity

    bytes ≈ 2 × L × T × Hkv × Dhead × dtype_bytes

    Multiply by active sequences and add block-table and allocator headroom.

    Roofline bound

    performance ≤ min(peak_FLOPs, bandwidth × arithmetic_intensity)

    Arithmetic intensity is operations per byte transferred from the limiting memory tier.

    Little's Law

    concurrency = throughput × mean_latency

    Use consistent units and a stable observation window; it is not a tail-latency model.

    Service utilization

    ρ = arrival_rate / total_service_rate

    Queue delay grows rapidly near saturation, so capacity plans require utilization headroom.

    Batch token budget

    step_tokens = Σ prefill_chunk_tokens + decode_sequences

    A token budget controls work more accurately than request count when prompt lengths vary.

    Speculation viability

    speedup requires accepted_tokens / verification_cost > baseline_rate

    Draft cost, target parallel verification, and acceptance length all matter.

    Cost per useful token

    cost = fleet_cost / tokens_meeting_quality_and_SLO

    Raw token throughput hides retries, rejected speculation, failures, and missed SLOs.

    Deployment drain budget

    drain_timeout ≥ request_p99 + network_and_cleanup_margin

    Streaming generations need enough time to finish or an explicit resumability strategy.

    Capstone

    Production readiness checklist

    A fast kernel is only one component of a dependable inference service.

    Model contract

    Version weights, tokenizer, chat template, generation defaults, adapters, and quantization metadata together.

    Capacity envelope

    Benchmark prompt/output distributions, concurrency, cache occupancy, TTFT, ITL, goodput, and OOM boundaries.

    Routing policy

    Balance load, cache affinity, deadlines, tenant fairness, model locality, and regional constraints.

    Observability

    Separate queue, prefill, decode, transfer, streaming, and cleanup time. Record model and engine versions.

    Safe deployment

    Warm the model, gate readiness, canary traffic, compare quality and latency, drain requests, and automate rollback.

    Failure behavior

    Test worker loss, cache loss, OOM, partial streams, regional failure, spot interruption, and dependency timeouts.

    How to use this track

    Read, predict, run, explain

    Passive reading creates vocabulary. Prediction and explanation create engineering judgment.

    1. Read the day. Write the bottleneck, invariant, and tradeoff in one sentence each.
    2. Predict behavior. Before running code, predict shapes, memory growth, accepted tokens, or queue movement.
    3. Run the closest module. Change one variable and explain the result using the theory.
    4. Answer the checkpoint. Do it aloud without terminology-only answers.
    5. Connect two layers. Example: explain how quantization changes model fit, batching capacity, and fleet cost.
